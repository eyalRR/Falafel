# פלאפלוצ׳יק וחומוסון: המסע להצלת הפיתה הגדולה (Falafel)

משחק הרפתקאות תלת-ממדי מבוסס Three.js בדפדפן.

## תיאור המשחק
משחק תלת-ממדי צבעוני ומהנה הכולל אנימציות, פיזיקה, אפקטים קוליים, ואתגרים להצלת הפיתה הגדולה.

## הפעלה
פתחו את הקובץ `index.html` בכל דפדפן מודרני, או הריצו שרת מקומי (Local HTTP Server), למשל:
```bash
npx serve .
```
או
```bash
python -m http.server 8000
```
