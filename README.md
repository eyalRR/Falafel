# פלאפלוצ׳יק וחומוסון: המסע להצלת הפיתה הגדולה (Falafel 3D)

משחק הרפתקאות תלת-ממדי מבוסס **Three.js**, **TypeScript** ו-**Vite** בדפדפן.

🎮 **שחקו עכשיו ברשת (Live Demo)**:  
👉 **[https://eyalrr.github.io/Falafel/](https://eyalrr.github.io/Falafel/)**

## תיאור המשחק
משחק תלת-ממדי עשיר וצבעוני הכולל:
- מודל תלת-ממדי מלא של **פלאפלוצ׳יק** (גרגרי שומשום ופטרוזיליה, סרט ראש כחול-לבן מתנפנף, עיניים מונפשות, תרמיל טיולים וסניקרס).
- מנוע פיזיקת ג'לי (Squash & Stretch) בהרמה, גרירה והטלה עם עכבר / מגע.
- מנוע סינתוז סאונד פרוצדורלי מלא (Web Audio API) ללא קובצי אודיו חיצוניים: מנגינות כלי נגינה (עוד, נבל, חליל, צ'לו, דרבוקה) ואפקטים קוליים חיים.
- 4 שלבים ואתרים ישראליים מרהיבים:
  1. **יפו העתיקה**: מגדל השעון, סירות מפרש, חתולי סמטאות וגלי הים.
  2. **הכנרת**: מי אגם, הר ארבל, מזח עץ וברווזים.
  3. **מצדה**: צוקי מדבר יהודה, שביל הנחש, ים המלח ויעל הרים.
  4. **הכותל המערבי בירושלים**: אבני הכותל, מנורת הזהב, פתקי תפילה ויונים מתעופפות.

## ארכיטקטורה
הפרויקט מאורגן במודולריות מודרנית:
- `src/core/`: מנוע הרינדור (`Engine`), מצלמה ובקרים רספונסיביים (`CameraManager`), תאורה (`Lighting`), ולולאת המשחק (`GameLoop`).
- `src/textures/`: מחוללי טקסטורות פרוצדורליות לקנבס (פלאפל, סרט ראש, חול ואבנים).
- `src/entities/`: דמויות המשחק (`Falafeltchik`, `Hummuson`, `KingCrumbs`).
- `src/environments/`: ניהול שלבים, שמיים וגופי מים (`EnvironmentManager`, `Jaffa`, `Kinneret`, `Masada`, `Kotel`).
- `src/physics/`: עיוות ג'לי, גרירה והטלה (`JellyDeformation`, `DragDropThrow`).
- `src/systems/`: מערכות חלקיקים, גלים וניהול שלבים (`ParticleSystem`, `StageManager`).
- `src/audio/`: מנוע סאונד פרוצדורלי (`AudioEngine`).
- `src/ui/`: ממשק משתמש ו-HUD צף (`UIManager`).

## הפעלה ופיתוח
1. התקנת תלויות:
```bash
npm install
```

2. הרצה מקומית עם שרת פיתוח מהיר:
```bash
npm run dev
```

3. בניית גרסת ייצור אופטימלית:
```bash
npm run build
```
התוצר ייבנה לתיקיית `dist/` ומוכן לפריסה ב-GitHub Pages, Netlify או כל שרת סטטי.
